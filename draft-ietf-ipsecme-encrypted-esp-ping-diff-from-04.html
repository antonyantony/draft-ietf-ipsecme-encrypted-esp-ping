    11.1. Linux XFRM
   
    Organization Linux kernel XFRM
   
    Name ESP Ping IP-TFS (https://github.com/antonyantony/linux/tree/
    esp-ping-iptfs)
   
    Description An initial implementation of the ESP Echo Protocol in
    the Linux kernel (net/ipv4/esp_ping.c), both encrypted and
    unencrypted. It adds an IPPROTO_AGGFRAG ping socket type for IPv4
    and IPv6, with a socket option to select the outbound SPI. It
    sends and receives encrypted ESP Echo Request and Reply packets
    carried in AGGFRAG_PAYLOAD inside an SA, and answers requests with
    Echo Replies. Unencrypted echo using SPI values 7 and 8 is
    implemented, and echo packets bypass the SPD. IKEv2 negotiation
    of ESP_ECHO_SUPPORTED is implemented in strongSwan. And uses
    busybox ping for testing.
   
    Level of maturity Alpha
